# folder-organizer
フォルダ仕分け 0.12

Windowsで自分のフォルダを整理するための試作です。
処理はPC内で行います。

起動
  1. ZIPを「すべて展開」します。
  2. Windows版のPython 3.10以上が入っているPCで START.bat を開きます。
     Pythonで直接開く場合は py -3 folder_organizer.py を実行します。
     TkinterはPythonのWindows版インストーラーで選べます。
  3. ウィンドウのタイトルが「フォルダ仕分け 0.12」になっていることを確認します。

使い方
  1. 最初は試したいフォルダをコピーし、そのコピーを選びます。
  2. 左側で対象のグループを開き、右側でファイルにチェックを入れます。
     チェック欄とファイル名のどちらからでも選べます。
  3. １件にチェックしたときは「代表を選んで整理」が使えます。名前を入力してから、
     プレビューで名前の変更（→）とバックアップ先（↳）を確認します。実行すると、代表を元の
     フォルダに残し、同じグループの残りを backup/年月日/グループ名/ に移動します。
     例は backup/2026-11-07/MRSR/ です。日付はPCのローカル日付です。
     既存の backup（Backup などの大文字・小文字違いを含む）を優先して使います。
     backup がまだなく「バックアップ」フォルダがある場合は、そちらを使います。
     同じ日付・同じグループのフォルダに追記し、同名には (2)、(3) を付けて保存します。
     コードは元の名前が初期値です。別のコードから呼び出している場合は、
     名前と移動先を確認してから実行してください。
  4. ２件以上にチェックしたときは「コードを比較する」が使えます。
     ２件では差分を、３件以上では選んだ全ファイルに共通する行と、
     それ以外の行をファイル別に表示します。一部にだけ共通する行も、
     「全ファイルには共通しない部分」に含めます。

分類と比較
  ・初期状態では選んだフォルダの直下を見ます。「サブフォルダも含める」を
    選ぶと、配下のファイルを相対パス付きで一覧に出します。backup、
    バックアップ、隠しディレクトリ（名前が . で始まるもの）は探索対象外です。
    フォルダをまたぐグループでは比較ができます。整理は同じフォルダ内で行います。
    単独のファイルを確認するときは「単独ファイルも表示」を選びます。
  ・同じ拡張子のファイルを対象に、名前から _8、_v2、_最終版 などの版表示を
    外して分類します。
  ・.m、.py、.txt、.md、.csv は256 KiBまで中身を読みます。
    中身が完全一致、または空白を整理した後の連続３行のパターンが十分似ている
    ファイルは、名前が異なっていても同じ候補グループに入ることがあります。
  ・.docx は本文の段落、.pptx はスライド内のテキスト、.xlsx はセルの値や数式を
    比較します。画像や装飾は比較対象外です。抽出した本文の上限は256 KiBです。
  ・PDF、.mlx、旧形式のOfficeファイルは、ファイル名・更新日時・サイズを表示します。
  ・３件以上の本文は、１件目から順に行を照合し、共通部分を絞り込みます。
    対応付けられた行を全件共通として表示します。

MATLABの参照先を比較
  1. .m ファイル２件以上にチェックし、「参照先を比較する」を押します。
  2. ファイル一覧を確認して「比較を開始」を押します。MATLAB が自動で
     見つからなかった場合は「MATLABを選ぶ」でインストール済みの MATLAB を
     指定します。使えるライセンスと -batch 対応の MATLAB が必要です。
  3. 追加の指定があるときは「詳細設定」を開き、対象ファイルごとに作業フォルダや
     追加の参照フォルダを設定できます。作業フォルダの初期値は各ファイルの
     親フォルダです。普段 addpath するフォルダは「追加」で優先順に指定します。
  ・ファイルごとに別の MATLAB セッションで静的解析します。画面には本体と
    検出できた参照先の一致・差分が表示されます。３件以上では一覧の１件目を
    基準に、２件目以降をそれぞれ比較します。完了まで数分かかることがあります。
  ・解析用の処理を起動し、対象コードと参照ファイルを読み取ります。
    実行時に決まる参照や、指定したパスに含まれない依存先は検出できないことが
    あります。表示の「一致」は検出したファイルの内容についての結果です。

代表バージョンを持ってきて整理
  1. 左下のボタンを押して、整理するコードのグループを選びます。表示中の
     グループが１つのフォルダにまとまっている場合は、初期値になります。
  2. 代表版のファイルを直接選ぶか、探すフォルダを選びます。探索では、サブフォルダ
     も対象にして、完全一致、内容の類似度、名前をもとに候補を表示します。
  3. 代表版と既存のファイルを比較し、バックアップに移す版を確認します。
     初期状態では既存の版すべてが選ばれています。残したいものはチェックを外します。
     行一致率は、空行と単独のコメント行を除き、行の前後の空白を無視して順に比べた目安です。
     50%未満では役割や処理が異なる可能性を表示します。
  4. 「バックアップに移す」から整理確認へ進み、代表版のコピー先フォルダ（↳）、
     保存名、バックアップ先を確認して実行します。別フォルダの代表版はコピーして使用します。
  ・本文を比較できる結果の右下から「差分の詳細」を開くと、変更箇所の前後を左右に表示します。
